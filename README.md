Mini e-commerce – Pratique JavaScript
Acceder au site : https://grdraphael.github.io/creation-site-e-commerce/

Petit projet réalisé pour mettre en pratique les notions vues sur OpenClassrooms autour de :
	•	fetch() et récupération de données JSON
	•	map(), filter() et sort()
	•	manipulation du DOM
	•	gestion d’un état dynamique (liste affichée, tri croissant/décroissant)

Les produits sont chargés depuis un fichier JSON puis affichés dynamiquement.
Il est possible de filtrer par catégorie et de trier les éléments visibles par prix.

Objectif : comprendre la logique des tableaux en JavaScript et leur interaction avec l’interface utilisateur.
